# Avatar pose prompts — Interests section (ChatGPT)

How to use:

1. Open a new ChatGPT chat and upload `docs/interest-pose-reference.png` (the
   avatar as it is on the site) with every prompt, so the character stays the
   same.
2. Paste one prompt below, as it is. One image per message.
3. Download the PNG and send it to Claude with its interest name. Claude trims
   it, converts it to webp and wires it in (`public/interests/poses/<id>.webp`).

Every prompt is complete on its own.
